# SAS PRO

منصة SAS PRO لتيليجرام: Mini App + اشتراكات Telegram Stars + تحليل PanWatch + أخبار وأحداث السهم + سجل التحليلات + رادار Telegram.

## البنية

- **PanWatch**: تتم مزامنته من المستودع الرسمي إلى `vendor/PanWatch` بواسطة GitHub Actions.
- **SAS PRO API**: FastAPI في `app/`.
- **Mini App**: الواجهة العربية RTL في `web/`.
- **الاشتراكات**: Telegram Stars مع مدد شهرية / 3 أشهر / سنة.
- **الحماية**: التحقق من Telegram WebApp `initData` بتوقيع HMAC على الخادم.
- **الانتهاء**: إيقاف PRO تلقائيًا، ومحاولة إزالة المستخدم من القناة الخاصة عند الانتهاء.
- **تنبيه الانتهاء**: رسالة واحدة قبل 3 أيام، وتُعاد دورة التنبيه عند التجديد.
- **توقيت السوق**: 09:30–16:00 بتوقيت نيويورك، مع مراعاة إغلاقات NYSE المبكرة.
- **الأخبار والأحداث**: موصل Finnhub اختياري.
- **SAS HOLIDAY RADAR**: أثناء إغلاق السوق الأمريكي، ترسل القناة أسعار BTC / Gold / Oil / S&P 500 / Nasdaq / Dow Jones كل ساعتين فقط.
- **Bitcoin movement alerts**: تنبيه مختصر عند حركة بيتكوين قدرها 1.5% أو أكثر، مع حد أدنى 90 دقيقة بين التنبيهات.
- **Market gate**: عند افتتاح الجلسة الأمريكية يتوقف Holiday Radar تلقائيًا ويُسمح برصد الأسهم؛ وبعد الإغلاق يعود وضع الأصول العالمية.
- **بيانات السوق**: موصل Twelve Data اختياري.
- **الشرعية**: لا يوجد نظام فحص شرعي أو تصنيف للأسهم؛ النص الموجود في الواجهة هو إخلاء المسؤولية المطلوب فقط.

## مزامنة PanWatch

ملف `.github/workflows/sync-panwatch.yml` يسحب:

`https://github.com/TNT-Likely/PanWatch`

ويضع نسخة المصدر داخل:

`vendor/PanWatch`

بعد ذلك يصبح السيرفر في الإنتاج مبنيًا من مستودع `pq070pq/sas` نفسه، وليس من خادم PanWatch خارجي.

> يجب الحفاظ على ملف LICENSE الخاص بـ PanWatch عند المزامنة.

## التشغيل على OVH

1. أنشئ ملف `.env` من `.env.example`.
2. ضع توكن البوت ومعرف المالك ومفاتيح مزودي البيانات.
3. بعد نجاح مزامنة PanWatch شغّل:

```bash
docker compose build
docker compose up -d
```

4. تحقق:

```
GET /health
```

يجب أن يعيد `ok=true`.

## Telegram Webhook

اضبط Webhook على:

`https://YOUR-DOMAIN.example/api/telegram/webhook`

واستخدم قيمة `TELEGRAM_WEBHOOK_SECRET` نفسها في رأس Telegram السري. يجب أن يكون Bot API قادرًا على الوصول إلى HTTPS.

## Mini App

اجعل رابط Mini App هو:

`https://YOUR-DOMAIN.example/`

ثم اربطه من BotFather.

## Telegram Stars

الخطط الافتراضية في `.env.example`:

- شهري: 500 ⭐
- 3 أشهر: 1200 ⭐
- سنوي: 3500 ⭐

يمكن تغيير الأسعار من متغيرات البيئة بدون تعديل الكود.

## إدارة الاشتراك

للمالك:

- `GET /api/admin/stats`
- `POST /api/admin/grant/{telegram_id}?days=30`
- `POST /api/admin/revoke/{telegram_id}`

ولا تُستخدم هذه المسارات إلا بعد التحقق من Telegram ID المالك.

## تنبيه الانتهاء

المجدول يعمل كل ساعة:

- إذا انتهى الاشتراك: يصبح غير فعال.
- إذا بقيت 72 ساعة أو أقل ولم يُرسل التنبيه: تُرسل رسالة واحدة.
- عند التجديد تُفتح دورة جديدة ويُعاد ضبط علامة التنبيه.

## متطلبات الإنتاج

- استخدم HTTPS.
- لا تضع `.env` أو مفاتيح API داخل Git.
- اجعل Bot Administrator في القناة الخاصة إذا أردت إزالة المنتهية عضويتهم.
- استخدم PostgreSQL بدل SQLite عند التوسع.
- احتفظ بنسخة احتياطية لقاعدة البيانات.
- لا تعرض مفاتيح API في الواجهة.

## الترخيص

PanWatch مشروع منفصل بترخيصه الخاص. تتم مزامنته كما هو ويجب الاحتفاظ بإشعار حقوق النشر وملف الترخيص الأصلي.
