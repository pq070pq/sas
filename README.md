# 💎 Signal Desk Pro - بوت التداول الذكي

بوت تيليجرام متكامل لرصد الانفجارات السعرية في الأسهم الأمريكية + تحليل ذكي عند المراسلة.

## ✨ المميزات

### 📊 رصد الانفجارات (في القناة)
- رصد تلقائي للأسهم المنفجرة +15%
- فلترة قوية: سعر، حجم، سيولة
- تنبيهات فورية مع الأخبار
- تبريد ذكي لمنع التكرار

### 🤖 التحليل الذكي (في الخاص)
- تحليل أي سهم أمريكي
- الزخم (قصير/متوسط/طويل)
- الحجم والسيولة
- المؤشرات الفنية (RSI, VWAP)
- اتجاه السهم
- آخر الأخبار مصنفة (إيجابي/سلبي)

### ⚠️ تنبيه شرعي
كل تحليل ينتهي بـ:
- هذا تحليل آلي وليس توصية
- شرعية الأسهم مسؤوليتك
